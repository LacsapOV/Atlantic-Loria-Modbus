# Atlantic Loria / Techneco Loria Duo - proprietary Modbus register map
# Updated 2026-11-14. Tested primarily on Duo 6008 R410A; community data on Duo 6004 R410A.
# One register per line: 41 aa bb cc Meaning; one legacy documented 42 write at the end.
# The proprietary function 0x41 reads a 3-byte identifier (NOT normal FC03 holding registers).
# IMPORTANT: data width is address-dependent: 05 often returns 1 byte, C1/C4/C6 often 2.
# For two-byte temperatures, signed big-endian / 10 unless the line specifies otherwise.
# Evidence labels: [6008 TESTED] = setting/display/A-B-A test on the 6008;
# [6008 OBSERVED] = repeatable correlation, exact sensor identity may still be uncertain;
# [6004 TESTED] = setting/display A-B-A test reported by ZAPPEL-non-ai on 6004;
# [6004 CORRELATED] = community evidence on 6004, not independently proven on 6008;
# [PROVISIONAL] = possible interpretation, do not treat as a manufacturer specification.
# More nuance, contradictory findings, all raw addresses: LORIA_MAPPING_NOTES.md.
# Community: https://github.com/LacsapOV/Atlantic-Loria-Modbus/issues/1
# No 0x42 write to unknown addresses. Reading data != permission to write it.

# Setpoints and weather-compensated CH control
41 c1 74 ec DHW setpoint (deg C; unsigned BE u16 / 10); verified 46->47->46 and 46->50->46 [6008 TESTED]
41 c4 35 6e Active calculated supply-water target (deg C; signed BE u16 / 10); CH responds to room setpoint, slope and foot; DHW about DHW target +5 K [6008 TESTED]
41 c6 15 04 Calculated water/CH demand target (deg C; signed BE u16 / 10); closely tracks C4 35 6E in CH [ORIGINAL; 6008 TESTED]
41 c1 0f ab Active supply-water target integer part in first response byte (deg C; second byte 00); CH/DHW changes [6008 OBSERVED]
41 05 12 36 Installer parameter 32: CH maximum supply-temperature setting (deg C; ONE data byte); follows display setting changes [6008 TESTED]

# Operating state and time
41 c4 0f c2 Operating phase (BE u16): 1=idle, 2=CH preparation, 3=CH active, 6=DHW preparation, 7=DHW active [6008 OBSERVED]
41 c4 30 fd Combined state: response byte0=stage (1=idle/prep, 2=startup, 3=active); byte1=phase matching C4 0F C2 [6008 OBSERVED]
41 c4 3f 57 Seconds-like counter (BE u16, increments about once/sec; reset/wrap and function unknown) [6008 OBSERVED]
41 c4 77 76 Controller year (BE u16, e.g. 0x07EA=2026) [6008 TESTED]
41 c4 77 79 Controller calendar month/day (byte0=month, byte1=day) [6008 TESTED]
41 c4 77 86 Controller clock hour/minute (byte0=hour, byte1=minute) [6008 TESTED]
41 c4 78 2c Controller weekday (BE u16, observed 1=Monday..7=Sunday) [6008 OBSERVED]
